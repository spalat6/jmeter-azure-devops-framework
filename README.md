# JMeter Azure DevOps Performance Framework

A reusable performance testing framework using Apache JMeter
and Azure DevOps Pipelines.

## Objectives

1. Automate JMeter test execution
2. Integrate performance testing into Azure DevOps
3. Generate HTML performance reports
4. Implement automated performance quality gates
5. Support configurable workload profiles

## Technology Stack

Apache JMeter, Java, Azure DevOps, GitHub, PowerShell
